# 测试计划

## 测试范围

基于产品设计文档，对以下核心功能进行测试：

### 1. 意图解析模块 (AIParserService)

| 测试用例 | 输入 | 预期输出 | 优先级 |
|---------|------|---------|--------|
| 城市解析 | "北京3日游" | city="北京", days=3 | P0 |
| 景点解析 | "故宫+天安门+长城" | attractions=["故宫","天安门","长城"] | P0 |
| 预算解析 | "预算500元/晚" | budget=500 | P1 |
| 交通偏好 | "想坐地铁" | transport_mode="transit" | P1 |
| 规则降级 | 无API时 | 使用简单规则解析 | P0 |

### 2. LLM Provider 模块

| 测试用例 | 场景 | 预期结果 | 优先级 |
|---------|------|---------|--------|

| OpenAI调用 | 配置有效API Key | 正常返回 | P1 |

### 3. POI 服务模块

## 测试环境

- Python 3.10+
- FastAPI
- httpx
- pytest

## 测试数据

测试数据存放在 `data/` 目录：

- `test_intents.json` - 意图解析测试用例
- `test_pois.json` - POI搜索测试数据
- `test_routes.json` - 路线优化测试数据

## 执行计划

1. **单元测试** - pytest tests/unit/
2. **集成测试** - pytest tests/integration/
3. **端到端测试** - pytest tests/e2e/

## 成功标准

- 单元测试覆盖率 ≥ 80%
- P0 用例 100% 通过
- P1 用例 ≥ 90% 通过
